# 🏅 منظومة المشروع القومي للياقة البدنية بالمعاهد الأزهرية
### Al-Azhar National Physical Fitness Platform (2026 / 2027)

منظومة إلكترونية متكاملة لإدارة ومتابعة **المشروع القومي للياقة البدنية بالمعاهد الأزهرية** على مستوى جمهورية مصر العربية، وفق المعايير الرسمية المعتمدة لقطاع المعاهد الأزهرية والإدارة المركزية لرعاية الطلاب.

---

## 🌟 المميزات والصفحات المكتملة

1. **لوحة التحكم المركزية (`/`)**: مؤشرات لحظية (KPIs)، نسبة إنجاز القياسات، الرسوم البيانية، ونسب التقديرات.
2. **عن المشروع (`/about`)**: وثيقة المشروع، الأهداف التربوية والصحية، والفئات المستهدفة.
3. **المناطق الأزهرية (`/regions`)**: التغطية الرسمية الشاملة لـ **27 منطقة أزهرية** بكافة المحافظات.
4. **الإدارات التعليمية (`/administrations`)**: قاعدة بيانات **202 إدارة تعليمية** مع المعاهد التابعة وإمكانية البحث والتصدير.
5. **المعاهد الأزهرية (`/institutes`)**: دليل المعاهد بجميع المراحل (ابتدائي / إعدادي / ثانوي / بنين / فتيات) وإدارتها.
6. **إدارة الطلاب (`/students`)**: تسجيل وتعديل واستيراد بيانات الطلاب وربطهم بالمعهد والفصل.
7. **بنك الاختبارات والمعايير (`/assessments`)**: محرك تقييم متطور يطابق جداول المساطر والدرجات الرسمية للأزهر.
8. **القياسات والنتائج (`/measurements`)**: رصد درجات الطلاب، حساب التقدير ومؤشر كتلة الجسم (BMI) آلياً، ومسار الاعتماد (مسودة ← مراجعة ← اعتماد).
9. **المنافسات والبطولات (`/competitions`)**: مسار التصفيات من المعهد إلى الإدارة ثم المنطقة والبطولة القومية للجمهورية، ولوحة شرف المتأهلين.
10. **المتابعة والتقييم الميداني (`/followup`)**: سجل الزيارات الميدانية لموجهي التربية الرياضية، وقوائم التحقق وفحص الملاعب.
11. **التقارير والإحصاءات (`/reports`)**: تقارير شاملة، رسوم بيانية تفاعلية، بطاقة لياقة بدنية فردية للطالب قابلة للطباعة الرسمية، وتصدير Excel/CSV.
12. **إدارة المستخدمين والصلاحيات (`/users`)**: نظام صلاحيات متدرج (RBAC) يغطي: مدير النظام، قطاع المعاهد، منسق المنطقة، موجه الإدارة، معلم المعهد، ولجان التحكيم.
13. **سجل العمليات والتدقيق (`/audit-log`)**: تتبع دقيق لكافة التعديلات والاعتمادات لضمان الحوكمة والنزاهة.
14. **الإعدادات وإدارة البيانات (`/settings`)**: ضبط العام الدراسي وفترة الرصد، وتصدير واستعادة نسخة احتياطية كاملة (JSON).

---

## 🛠 التقنيات المستخدمة

- **Frontend**: React 19 + TypeScript + Vite 8
- **Styling**: Modern Royal Government CSS Design System (Cairo Font + Full RTL)
- **State Management**: Zustand مع الحفظ المحلي التلقائي (`LocalStorage Persistence`)
- **Charts**: Recharts للرسوم البيانية التفاعلية
- **Icons**: Lucide React
- **Deployment**: Vercel Ready (`vercel.json` SPA Rewrites Included)

## 🚀 التشغيل المحلي (Local Development)

```bash
# الانتقال لمجلد المشروع
cd azhar-fitness-platform

# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
```

## 📦 خطوات الرفع على GitHub (Push to GitHub)

1. افتح موجه الأوامر (Terminal) في مجلد المشروع ونفّذ الأوامر التالية:

```bash
git init
git add .
git commit -m "feat: منظومة المشروع القومي للياقة البدنية بالأزهر مكتملة 100%"
git branch -M main
```

2. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً باسم: `azhar-fitness-platform`).
3. اربط المستودع وارفع الكود:

```bash
git remote add origin https://github.com/USERNAME/azhar-fitness-platform.git
git push -u origin main
```

*(استبدل `USERNAME` باسم حسابك على GitHub)*

## ⚡ خطوات النشر على Vercel (Deploy to Vercel)

المشروع جاهز ومُهيأ بالكامل بملف `vercel.json` لتفادي مشكلات التوجيه (404 on refresh).

### الطريقة الأولى: عبر موقع Vercel (مستحسنة وبسيطة):
1. ادخل على [vercel.com](https://vercel.com) وسجّل دخولك بحساب GitHub.
2. انقر على **"Add New Project"** ثم اختر مستودع `azhar-fitness-platform`.
3. اضغط **Deploy** مباشرة دون الحاجة لتغيير أي إعدادات!

### الطريقة الثانية: عبر Vercel CLI:
```bash
npm i -g vercel
vercel
vercel --prod
```
